پرسش‌های متداول

هر آنچه قبل از نصب و استفاده از نوااسمارت باید بدانید.

آیا نوااسمارت واقعاً ۱۰۰٪ رایگان است؟

بله! نوااسمارت کاملاً متن‌باز (Open-Source) و رایگان است. تمامی امکانات شامل هوش مصنوعی‌های داخلی، تایمر، کنترل مدیا و لانچر بدون هیچ‌گونه پرداخت یا تبلیغات عرضه می‌شوند.

چگونه می‌توانم از هوش مصنوعی بدون API Key استفاده کنم؟

نوااسمارت به طور پیش‌فرض از ارائه‌دهنده قدرتمند Nova Free استفاده می‌کند که دسترسی مستقیم به مدل‌های OpenAI، DeepSeek و Qwen را فراهم می‌سازد. در صورت تمایل می‌توانید کلید اختصاصی خود یا مدل‌های محلی Ollama را نیز متصل نمایید.

نوااسمارت روی چه نسخه‌هایی از ویندوز اجرا می‌شود؟

نوااسمارت روی ویندوز ۱۰ (نسخه 64-bit) و تمامی نسخه‌های ویندوز ۱۱ به صورت کاملاً روان، کم‌مصرف و سازگار با سیستم کنترل صدای پیشرفته ویندوز اجرا می‌شود.

آیا اطلاعات کلیپ‌بورد و چت‌های من امن هستند؟

کاملاً! تمام اطلاعات شما فقط روی سیستم خودتان ذخیره می‌شود و هیچ دیتایی به سرورهای خارجی ارسال نمی‌گردد. کلیپ‌بورد هوشمند نوااسمارت اطلاعات حساس مانند رمز عبور و شماره کارت‌ها را شناسایی و فیلتر می‌کند.
